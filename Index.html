Panduan Deploy ke GitHub & Vercel

Langkah singkat menerbitkan aplikasi ini ke tautan masbadel-vector.vercel.app.

1

Buat Repositori GitHub & Push index.html

Simpan berkas ini sebagai index.html lalu jalankan baris perintah berikut di terminal folder Anda:

git init
git add index.html
git commit -m "feat: Vectorizer Studio with BG Removal & History"
git branch -M main
git remote add origin https://github.com/USERNAME-ANDA/masbadel-vector.git
git push -u origin main
2

Hubungkan ke Vercel (vercel.com)

  1. Buka Vercel.com dan masuk menggunakan akun GitHub Anda.
  2. Pilih tombol "Add New..." → "Project".
  3. Impor repositori masbadel-vector.
  4. Biarkan Framework Preset pada "Other" (karena berbasis Client-side SPA murni).
  5. Klik tombol Deploy.
3

Tetapkan Domain masbadel-vector.vercel.app

Setelah proyek selesai dideploy, masuk ke menu Settings → Domains di dashboard Vercel Anda, lalu pastikan domain yang aktif adalah masbadel-vector.vercel.app.

Operasi Berhasil!
